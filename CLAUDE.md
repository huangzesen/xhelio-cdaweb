# CLAUDE.md — cdawebmcp

## Project Overview

`cdawebmcp` is a standalone Python package that exposes NASA's CDAWeb (Coordinated Data Analysis Web) as an MCP (Model Context Protocol) server. Any MCP-compatible LLM client can use it to discover missions, load mission-specific system prompts, browse dataset parameters, and fetch CDF data.

## Implementation Plan

Read `docs/plans/2026-03-09-cdawebmcp-plan.md` for the full step-by-step plan (10 tasks). The design doc is at `docs/plans/2026-03-09-cdawebmcp-design.md`.

## Key Design Decisions

1. **`fetch_data` returns metadata + file path, NOT data inline.** Data is written to a temp file on disk. The response includes rich per-column statistics (`min, max, mean, std, nan_ratio`) so the caller can judge data quality before reading the file.
2. **One MCP server serves all ~40+ CDAWeb missions.** `browse_missions` is the discovery entry point. `load_mission` returns a full system prompt that turns any LLM into a mission specialist.
3. **Temp file lifecycle is caller-owned.** The MCP server writes but does not delete temp files.
4. **Mission catalog JSONs are bundled** in `src/cdawebmcp/data/missions/` and generated by `scripts/build_catalog.py` from the CDAWeb REST API.

## Tech Stack

- Python 3.10+
- `mcp` (FastMCP) — MCP server SDK
- `cdflib` — CDF file reading
- `pandas` / `numpy` — DataFrame operations
- `requests` — HTTP client for CDAWeb API

## Commands

```bash
# Install in dev mode
pip install -e ".[dev]"

# Run tests
python -m pytest tests/ -v

# Run the MCP server
python -m cdawebmcp

# Build/rebuild mission catalog from CDAWeb API
python -m cdawebmcp.scripts.build_catalog
```

## Package Structure

```
src/cdawebmcp/
    __init__.py          # Package entry point
    __main__.py          # python -m cdawebmcp
    server.py            # MCP server (FastMCP) — 4 tools
    catalog.py           # Mission JSON loading + browse_missions
    prompts.py           # Prompt assembly for load_mission
    metadata.py          # Parameter metadata (Master CDF fetch + cache)
    fetch.py             # CDF download + file output + stats
    http.py              # HTTP client with retry logic
    data/
        missions/        # Bundled mission JSON files
        prompts/         # Prompt templates (generic_role.md, cdaweb_role.md)
    scripts/
        build_catalog.py # CDAWeb API → mission JSONs
```
